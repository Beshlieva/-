Создай полноценный современный веб-дизайн UX/UI для сайта профориентационного теста «Карта интересов».

## 1. ЗАДАЧА ПРОЕКТА

Это веб-приложение для прохождения профориентационного теста на основе методики «Карта интересов» А.Е. Голомштока.

В тесте:

* 174 утверждения;
* 5 вариантов ответа на каждое утверждение;
* 29 направлений профессиональной деятельности;
* результат показывает выраженность интереса пользователя к каждому направлению;
* направления в результате сортируются от наиболее выраженного интереса к наименее выраженному.

Тест рассчитан прежде всего на школьников и молодых людей, но интерфейс должен выглядеть современно и подходить также взрослым пользователям.

Не копируй визуальный стиль старых сайтов с тестами. Сделай современный продукт уровня качественного EdTech / career-tech сервиса.

# 2. ОБЩИЙ СТИЛЬ

Стиль:

* современный;
* спокойный;
* дружелюбный;
* минималистичный;
* интеллектуальный;
* немного playful;
* без ощущения медицинского теста;
* без ощущения школьного экзамена;
* без перегруженности;
* много свободного пространства;
* большие скругления;
* мягкие тени;
* аккуратная типографика;
* хорошие визуальные иерархии.

Основная эмоция интерфейса:

«Мне интересно узнать о себе».

Не использовать агрессивные красные/зелёные цвета, которые создают ощущение «правильно / неправильно».

Не использовать кислотные цвета.

Не использовать чрезмерные градиенты.

# 3. ЦВЕТОВАЯ СИСТЕМА

Основной интерфейс — светлый.

Фон:

* очень светлый тёплый серо-бежевый или почти белый.

Основной текст:

* тёмный графитовый, а не абсолютный чёрный.

Вторичный текст:

* приглушённый серо-графитовый.

Акцент интерфейса:

* спокойный синий/индиго или другой нейтральный технологичный цвет.

## САМАЯ ВАЖНАЯ ЧАСТЬ — ЦВЕТА ОТВЕТОВ

Пять вариантов ответа должны образовывать мягкий цветовой спектр.

От положительного отношения к отрицательному:

1. Очень нравится — мягкий жёлтый / золотистый
2. Нравится — мягкий янтарный / светло-оранжевый
3. Не знаю — нейтральный кремовый / светло-серый
4. Не нравится — приглушённый терракотовый
5. Очень не нравится — мягкий коралловый

Цвета должны быть пастельными и ненасыщенными.

НЕ использовать:

* ярко-красный;
* ярко-зелёный;
* кислотно-жёлтый;
* насыщенный оранжевый.

Цвет ответа должен восприниматься как визуальная шкала отношения, а не как оценка правильности.

# 10. СОСТОЯНИЯ ОТВЕТОВ

Создай полноценные UI states для каждой карточки:

### Default

Светлый фон, мягкий цветовой оттенок.

### Hover

Небольшое поднятие карточки.

### Selected

* более выраженная граница;
* небольшая галочка;
* немного более насыщенный цвет;
* мягкая тень.

### Focus

Хорошо заметный focus state для клавиатурной навигации.

### Disabled

При необходимости приглушённый вариант.

После выбора ответа автоматически переходить к следующему вопросу через короткую плавную анимацию.

Не делать резких переходов.

# 11. НАВИГАЦИЯ

Внизу:

«Назад»

и индикатор прогресса.

Основной UX:

При возврате назад ранее выбранный ответ должен быть сохранён.

# 22. UX-ПРИНЦИПЫ

Главный принцип:

Пользователь должен понимать, что делать, без инструкции.

На каждом экране должен быть один очевидный основной action.

Не перегружать интерфейс.

Не использовать большое количество текста во время прохождения теста.

Пользователь должен чувствовать прогресс:

«24 из 174»

Но не создавать ощущение долгого экзамена.

Можно использовать небольшие мотивационные сообщения после определённых этапов:

«Ты уже прошёл 25%»

«Половина готова»

Но не делать их навязчивыми.

---

# 23. ДОСТУПНОСТЬ

Обязательно:

* достаточный контраст;
* большие кликабельные области;
* keyboard focus;
* понятные hover/selected states;
* не полагаться только на цвет для определения выбранного ответа;
* выбранный ответ должен дополнительно обозначаться рамкой/иконкой;
* текст должен быть читаемым на мобильных устройствах.

---

# 24. АНИМАЦИИ

Использовать минимальные micro-interactions:

* плавное появление вопроса;
* лёгкий slide/fade при переходе;
* hover карточки;
* мягкое заполнение progress bar;
* плавное появление результата.

Не использовать:

* резкие bounce-анимации;
* чрезмерные 3D эффекты;
* конфетти после каждого вопроса;
* чрезмерные градиенты.

После завершения теста можно использовать одну аккуратную celebratory animation.

---

# 25. ВАЖНЫЙ ВИЗУАЛЬНЫЙ ПРИНЦИП

Интерфейс должен восприниматься не как «тест с правильными ответами», а как:

«исследование собственных интересов».

Поэтому не использовать красный цвет как символ ошибки.

Если пользователь отвечает «Очень не нравится», это НЕ ошибка.

Это просто один из вариантов отношения.

Цвета должны отражать спектр отношения, а не оценивать пользователя.
