# Данные теста для backend

`categories.json` (29 направлений) и `questions.json` (174 вопроса) выгружены из `src/data/questions.ts`
и нужны, чтобы загрузить справочники в MySQL, не перепечатывая их вручную.

**Источник истины — `src/data/questions.ts`.** Если вы меняете вопросы, обновляйте и эти файлы,
и увеличивайте `TEST_VERSION` в `src/types/index.ts`, чтобы старые и новые результаты не смешивались.

Шкала ответов: `2` очень нравится, `1` нравится, `0` не знаю, `-1` не нравится, `-2` очень не нравится.
