# База данных Supabase

Все данные (пользователи, попытки, ответы, результаты) хранятся в облачной базе Supabase.
Логика теста (таймер 15 с, пропуски, повторные круги, подсчёт баллов) выполняется **в базе** — в функциях
из `rpc_attempts.sql`, поэтому подделать время или результат из браузера нельзя.

## Файлы

| Файл | Что делает |
|---|---|
| `schema.sql` | Таблицы, связи, индексы, триггер создания профиля при регистрации |
| `seed.sql` | Справочники: 20 регионов, 29 направлений, 174 вопроса (**очищает и заполняет заново** только эти три таблицы) |
| `rls.sql` | Права доступа (Row Level Security) |
| `rpc_attempts.sql` | Прохождение теста: создание попытки, ответ, пропуск, повторный круг, завершение, история |
| `admin.sql` | Аналитика для панели администратора (`/#/admin`) |

Все скрипты, кроме `seed.sql`, можно запускать повторно — они ничего не ломают и не удаляют данные пользователей.

## Как применить

Supabase → проект → **SQL Editor** → New query → вставить содержимое файла → **Run**. По порядку:

1. `schema.sql`
2. `seed.sql` — только при первой установке (справочники уже есть — пропустить)
3. `rls.sql`
4. `rpc_attempts.sql`
5. `admin.sql`

## Настройки в панели Supabase

**Authentication → URL Configuration**

- *Site URL*: `https://karta-interesov.onrender.com`
- *Redirect URLs*: добавить `https://karta-interesov.onrender.com/**` и `http://localhost:5173/**`

Без этого ссылка из письма подтверждения ведёт на `localhost`.

**Authentication → Sign In / Providers → Email → Confirm email**

- Включено: после регистрации приходит письмо, войти можно после перехода по ссылке.
- Выключено: вход сразу после регистрации.

Приложение работает в обоих режимах. Учтите, что встроенная почта Supabase отправляет лишь несколько писем
в час. Для реального потока пользователей подключите свой SMTP (Authentication → Emails → SMTP Settings)
или отключите подтверждение email.

## Администратор

Зарегистрируйтесь на сайте обычным способом, затем в SQL Editor выполните:

```sql
UPDATE public.profiles SET role = 'admin' WHERE email = 'ваш@email';
```

Вход в панель: `https://karta-interesov.onrender.com/#/admin` (email и пароль этой учётной записи).

## Ключи

Во frontend (переменные `VITE_*`) нужен только **publishable/anon** ключ. Он публичный по определению:
данные защищают политики RLS и проверки внутри функций. **Секретный ключ (`sb_secret_…`) никогда не
указывайте в `VITE_*` переменных и не коммитьте** — он даёт полный доступ к базе в обход RLS.
